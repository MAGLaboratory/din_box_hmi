# DIN Box HMI

This repository is for creating an HMI interface with a 4-01-5 DIN rail box
which can be purchased from retailers at the big road / middle kingdom.

The ABS front panel is machined and there are various components and
workholding pieces that are 3d printed.

The circuit boards inside the HMI are purchased from your typical boardhouse.

## Motivation

DIN rails are cool.
